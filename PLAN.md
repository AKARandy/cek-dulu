# PLAN — cek-dulu

Open eKYC pipeline for Indonesian ID cards (KTP): document QA, field detection,
OCR, NIK + cross-field validation, face matching, redaction. Served as FastAPI +
Gradio demo. CPU-only, pretrained-only, license-clean (no AGPL).

## Why this project

- Indonesian CV employment clusters on eKYC (Nodeflux, Verihubs, GLAIR, ADVANCE.AI).
  Nodeflux's Vision AI Engineer post lists exactly: Python, Docker, ONNX, FastAPI.
- Lane leader on GitHub (ktp-ocr, ~166 stars) ships no benchmarks, no API, no demo.
- Extends the author's arc: QUACKO (receipt OCR + accuracy baselines) and the
  Kemenhub data-quality pipeline (23 validation checks) -> identity documents with
  field-level validation rules.

## Hard rules

1. **Synthetic data only.** Every KTP image is generated by this repo (fake names,
   valid-structure NIKs, SPECIMEN watermark). No real PII, ever.
2. License-clean models only. Apache/MIT preferred; every model's license recorded
   in the README license table. No Ultralytics (AGPL).
3. Benchmarks before claims. Numbers in the README come from scripts/benchmark.py
   runs committed with their raw outputs.
4. README is production grade: demo GIF above the fold, real system screenshots,
   curl examples, benchmark tables, honest limitations.

## Modules

- `validators/` — NIK structure (admin codes, DOB encoding incl. the +40 female
  convention), cross-field consistency. Pure Python, no model deps, fast CI.
- `app/synthetic_ktp.py` — Pillow generator; emits image + ground-truth JSON
  including exact field bboxes (rendering = free gold annotations for detection
  benchmarks).
- `app/qa.py` — document QA gates: blur, glare, skew, size, with rejection reasons.
- `app/detect.py` — field detection/cropping (Florence-2-base grounding; OWL-ViT
  fallback).
- `app/ocr.py` — per-crop OCR (PaddleOCR primary, Tesseract fallback).
- `app/face.py` — ArcFace-family ONNX similarity, honest thresholds.
- `app/redact.py` — blur NIK/address/photo on output images.
- `app/api.py` — FastAPI: /ktp/extract, /ktp/validate, /match, /redact, /health.
- `demo/app.py` — Gradio: confidence bars, validation verdicts, match gauge,
  redaction toggle.
